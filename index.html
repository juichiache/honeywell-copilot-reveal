Slide 1 - Title

Case Study: Why Copilot Stays in Search Mode

Honeywell: From Copilot training to customer-owned AI-assisted iteration

Slide 2 - Leadership Framing

Leadership Summary

Key message: Honeywell moved from "AI could help with modernization" to customer-owned AI-assisted planning and iteration.

  • Started with: AI to help with legacy modernization
  • Microsoft delivered: Copilot training and Agentic SDLC workshops
  • Real work surfaced implementation friction the training did not solve
  • We installed a spec-driven thinking system Copilot could operate against
  • Customer now runs planning and iteration through AI on their own
  • Strongest proof: Gary is applying the pattern to two more projects without Microsoft support
Bottom line: Microsoft's value was the framework, not the hand-holding.
Slide 3 - The Reality

Senior Engineers Still Use Copilot Like Advanced Search

Key message: The default state of Copilot adoption is search mode.

Most of the org treats Copilot like an advanced Google search.
Bottom line: Copilot stays in Q&A mode when work has no durable system for Copilot to operate against.
Slide 4 - The Adoption Gap

Knowing the Mechanics != Running Work Through Copilot

Key message: Training can teach what Copilot can do, but it does not automatically change how engineering work is executed.

The average one does not understand agents or skills.
Agents are still confusing.
Bottom line: Feature awareness is not workflow transformation.
